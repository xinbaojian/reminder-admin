## 产品概述

根据接口文档实现定时任务管理功能页面,为用户提供可视化的定时任务配置管理界面。

## 核心功能

- 定时任务列表展示:以表格形式展示任务名称、任务键、Cron表达式、描述、状态、创建时间、更新时间等信息
- 创建定时任务:通过表单对话框创建新的定时任务配置
- 编辑定时任务:修改现有任务的任务名称、Cron表达式、描述等信息
- 删除定时任务:删除自定义定时任务(系统默认任务不可删除)
- 状态切换:启用或禁用定时任务
- 重载任务:手动重新加载所有定时任务配置
- Cron表达式帮助:提供常用Cron表达式示例和字段说明

## 技术栈选择

- 前端框架:Vue 3 + Composition API
- UI组件库:Element Plus
- 状态管理:Vue reactive
- HTTP请求:项目统一的request工具

## 实现方案

采用与项目现有页面一致的架构模式,实现API层和页面层的分离:

- API层封装所有接口调用
- 页面层使用el-card+el-table+el-dialog组合
- 状态管理使用reactive统一管理

## 性能优化

- 表格数据懒加载,仅在查询时请求
- 表单验证实时反馈,减少无效提交
- 状态切换直接操作,无需刷新整页

## 设计风格

采用简洁现代的企业级管理系统风格,使用卡片式布局,表格展示数据,对话框表单实现CRUD操作。整体风格与项目现有页面保持一致,确保用户体验的统一性。

## 页面布局

### 顶部操作区

- 左侧:搜索框(按任务名称搜索)+搜索按钮
- 右侧:添加任务按钮+重载任务按钮

### 表格区域

列配置:

- 任务名称(显示名称,宽度120px)
- 任务键(唯一标识,宽度150px)
- Cron表达式(宽度120px,提供悬停提示显示执行时间)
- 任务描述(自适应宽度,超出省略)
- 状态(标签显示,启用为绿色,禁用为灰色)
- 创建时间(宽度160px)
- 更新时间(宽度160px)
- 操作(固定右侧,宽度150px)

操作列按钮:

- 编辑:打开编辑对话框
- 删除:二次确认删除(系统任务不显示或禁用)
- 启用/禁用:切换状态

### 表单对话框

添加/编辑任务表单:

- 任务名称(必填,文本输入,最大100字符)
- 任务键(创建时必填,文本输入,最大100字符;编辑时禁用)
- Cron表达式(必填,文本输入,最大100字符,右侧显示帮助按钮)
- 任务描述(选填,文本域,最大255字符)
- 状态(开关选择:启用/禁用)

### Cron表达式帮助

对话框或Popver显示:

- 常用表达式示例表格
- 字段说明(秒/分/时/日/月/周取值范围)
